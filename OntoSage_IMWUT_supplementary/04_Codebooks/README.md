Each PDF starts with a short note: what the document is, which part of the article it supports, how its terms map to the article's, and the edits made for anonymity. The text after the note is the codebook as used, with those edits only. For both Part A versions, the note gives the SHA-256 of the original file, recorded when each version was frozen.

The answer-label rubric is in `03_Answer_label_rubric`. The coded data are in `08_Data`.
