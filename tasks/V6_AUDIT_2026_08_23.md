# V6 implementation audit — 2026-08-23

**Question asked:** is V6 implemented as planned, half-implemented, or wrongly implemented —
and does the core thesis hold (*add data as TTL/docs → OntoSage answers it, zero code change,
building-agnostic*)?

**Method:** not the tracker's word for it. For every turn marked `done`, three checks:
(1) the module exists, (2) the **live pipeline imports it** (tests don't count),
(3) the property it depends on has **instances in the graph**, not just a TBox definition.
This is the same check that already exposed T13/T16/T17 (BUG-237); it was run against all of
them this time.

---

## Verdict in one paragraph

The plan is sound and does not need rewriting. The execution has a single systemic defect,
repeated across ~10 turns: **decision logic was built and unit-tested, and the wiring that
makes the live system use it was skipped — then the turn was marked done against acceptance
criteria written about live behaviour.** Separately, the TTL work stopped at the schema layer:
**14 of 15 V6 TBox properties have zero instances in any building's graph**, so every gate
that reads them is inert even when wired. Nothing found is architecturally wrong; nothing
needs rebuilding; the building-agnostic guarantees hold everywhere they were checked. The gap
is wiring and instance data — both cheap now that the chokepoint/advisory pattern is proven
end to end.

## Why this keeps happening (so the fix is structural, not another sweep)

Every instance has one shape: **an interface whose absent side degrades to a legal value.**
`gate_verdicts` defaulting to empty; `getattr(adapter, "table", None)`; a documented bus key
nothing writes; a DictWriter filling a missing column with `""`; a TBox term with no ABox.
None of them raise. The countermeasure that has worked this week is also uniform: a test that
asserts **reachability or population**, not existence — "the pipeline imports this", "every
declared column is written", "this property has instances or the gate reports itself
not-evaluated". The rewire wave below adds that test per module as it lands.
