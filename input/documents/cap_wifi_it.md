# Abacws Building — Wifi It

Wifi coverage is provided by Cardiff University's 'eduroam' network throughout the building. Guests can use 'CU_Guest' wifi (registration required). Wired ethernet ports are available in offices, labs, and some study areas. IT support is provided by the Cardiff University IT Service Desk (itservicedesk.cardiff.ac.uk, 029 2251 1111). Printer/MFD devices are on every floor (PaperCut system). Server rooms are located on Floor 2 and Floor 4.
