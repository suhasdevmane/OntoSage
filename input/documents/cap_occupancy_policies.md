# Abacws Building — Occupancy Policies

Occupancy limits are set per room and displayed on the door. The building's maximum permitted occupancy is determined by fire safety regulations and is managed by building management. Overcrowding should be reported to Security. Real-time occupancy monitoring is limited — the building has presence sensors in some areas but not a full head-count system. For fire safety purposes, the building fire roll-call system is managed by floor wardens.
