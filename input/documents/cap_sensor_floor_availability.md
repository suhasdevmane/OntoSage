# Abacws Building — Sensor Floor Availability

Live sensor data is currently available for FLOOR 5 ONLY. Floor 5 is the only floor connected to OntoSage with streaming environmental telemetry — air temperature, CO2, and relative humidity, by zone. The Ground floor and Floors 1, 2, 3 and 4 do NOT currently have sensors connected to the system, so no live temperature, CO2, or humidity readings are available for those floors yet. Those floors ARE fully mapped in the building's floor plans and ontology (you can still ask about their rooms, areas, adjacency, amenities, fire safety, access, etc.), but they do not stream sensor data at this time. If you ask for a live reading on the Ground floor or Floors 1-4, the system cannot return a measured value and will tell you data is unavailable for that floor. Sensor rollout to the remaining floors is planned but not yet live.
