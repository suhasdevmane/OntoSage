# Abacws Building — Access Control

Access to Abacws uses a proximity card (swipe card / fob) system. All external doors and internal secure areas require a valid Cardiff University card or visitor pass. General academic areas (open-plan offices, study spaces) are accessible to all card holders during standard hours (07:00–22:00 weekdays, 08:00–18:00 weekends). Labs, server rooms, and restricted areas require specific access grants — request via IT Service Desk. After-hours access is available to staff and registered postgraduate students. Visitors must sign in at reception and be escorted. Security is staffed 24/7 at the main reception.
