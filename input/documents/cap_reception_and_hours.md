# Abacws Building — Reception And Hours

Abacws Reception (Ground Floor, main entrance) is open: Monday–Friday 09:00–16:30; Saturday and Sunday — Closed. The building itself has broader access hours (07:00–22:00 weekdays, 08:00–18:00 weekends) for card-holders — reception staffing and visitor sign-in are only available during the hours above. Out-of-hours queries should be directed to Cardiff University Security Services (029 2087 4444, 24/7).
